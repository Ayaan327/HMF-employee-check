# Project brief — HMF Attendance

**HMF** = HMF Engineering and Project Management Consultants (UK and Pakistan offices; https://hmfconsultants.co.uk).

## Users
Employees (check in/out, view own hours and leave, request leave), managers (direct reports), HR admins (office-scoped),
system administrators (configuration).

## Implemented
Login with server-side sessions; office-local attendance (present/absent/other); profiles; scoped roles; schedules;
clock-in/out and hours; corrections with audit history; CSV import/export; annual leave with balances, approvals,
holiday calendars and attendance integration; privacy redaction; responsive, accessibility-tested UI.

## Not yet
Microsoft 365 sign-in, HMF-owned hosting and domain, backups/restore, reminders, retention, partial-day leave,
approved-leave amendments, accrual. No payroll. See `docs/HOSTING-M365-DOMAIN-ASSESSMENT.md`.
